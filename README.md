# Desfile do Pedido de Desculpas

App Android: bonecos em pixel art (cowboy, rei, ogro, cavaleiro, mago, pirata, ninja, robô, viking e chef) correm da esquerda para a direita. No final vem um cavalo puxando uma carroça com um presente. Ao tocar no presente, ele abre e aparece uma mensagem de desculpas.

## Mudar a mensagem
Edite `TITULO` e `MENSAGEM` no topo do script em `docs/index.html` (a mesma página é usada no APK e no link).

## Baixar o APK
A cada push, o GitHub Actions compila o app. O APK fica em **Releases → Desculpa APK → Desculpa.apk**. Abra esse link no celular, baixe e instale (permita "instalar apps de fontes desconhecidas").
